# AI-Driven-Cyber-Defense-Pipeline 
# LIVE DEMO: https://ai-4ae26d3fd8f7496fbc53fc7abf830ee9.ecs.us-east-1.on.aws/

An end-to-end **Security Operations Center (SOC) pipeline** that combines **Machine Learning, Rule-Based Detection, Threat Intelligence, Large Language Models (LLMs), RAG, and SOAR automation** to detect, analyze, and respond to cybersecurity threats in real time.

---

## 🚀 Overview

This project simulates a modern SOC architecture with layered intelligence:

- 🔍 ML-based anomaly & attack detection  
- ⚙️ Rule-based correlation engine  
- 🌐 Threat intelligence enrichment  
- 🧠 LLM + RAG-based incident reasoning  
- ⚡ SOAR-style automated response playbooks  

It demonstrates how **traditional cybersecurity + GenAI** can be integrated into a unified detection-to-response system.

---

## 📥 Input

- Raw network/security logs (user input or dataset)
- Supported datasets:
  - CICIDS2017
  - UNSW-NB15
